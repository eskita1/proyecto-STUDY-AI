# Technical Decision 001: El backend inicial utiliza FastAPI

## Decisión

El backend inicial de StudyAI utiliza FastAPI.

## Motivo

El proyecto ya cuenta con una aplicación mínima en FastAPI. Mantener esta base permite avanzar sin introducir cambios tecnológicos antes de que el producto los necesite.

## Consecuencia

Por ahora, las nuevas capacidades de backend se incorporarán sobre FastAPI, manteniendo la estructura simple y evitando capas innecesarias.
