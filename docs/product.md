# Producto

## Problema

La información académica de un estudiante suele estar repartida entre programas, guías, apuntes, parciales y herramientas aisladas. Esto hace difícil saber qué se está cursando, qué contenido falta recorrer y qué conviene estudiar o practicar a continuación.

## Usuario objetivo inicial

El primer usuario es un estudiante universitario que cursa una o más materias y quiere seguir su avance de manera ordenada.

## Visión

StudyAI será un acompañante académico que permita representar la estructura de las materias, registrar el recorrido del estudiante y convertir esa información en una guía útil para estudiar.

El producto crecerá de forma gradual. En versiones futuras podrá trabajar con programas, guías y ejercicios, y usar IA para ayudar a interpretar material y proponer práctica. La información y las métricas académicas seguirán siendo comprensibles y verificables por el estudiante.

## Propuesta de valor

StudyAI busca reunir el contexto académico que hoy está disperso para que el estudiante pueda responder preguntas simples pero importantes:

- ¿Qué materias y temas estoy cursando?
- ¿Hasta dónde llegó la cursada?
- ¿Qué contenido ya recorrí?
- ¿Qué temas necesito practicar?
- ¿Qué debería estudiar después?

## Qué no intenta ser StudyAI

StudyAI no busca reemplazar a docentes, instituciones ni plataformas de gestión académica. Tampoco es solo una aplicación de notas, un repositorio de archivos o un generador automático de respuestas.

## Principios del producto

- Priorizar claridad antes que automatización.
- Diferenciar progreso, ritmo de cursada y dominio del contenido.
- Usar reglas determinísticas para las métricas académicas críticas.
- Incorporar IA como apoyo, no como fuente de verdad.
- Construir de forma gradual, evitando complejidad que todavía no aporta valor.
